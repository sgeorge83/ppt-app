Privacy Policy — WordOnAir Slides

Effective date: November 10, 2026
Product: WordOnAir Slides for Windows, and the WordOnAir Slides Chrome extension
Publisher: WordOnAir Labs · wordonair.com

WordOnAir Slides places World English Bible and Urdu Geo verses on PowerPoint slides for pastors. It is a free Windows app and a free Chrome extension. It works without an account, without advertising, and without collecting personal information.

1. Information the Windows app handles

The app does not ask for your name, email, phone number, contacts, or a Microsoft account.

The church name, chosen theme, language, and the path to a logo you pick are stored only on this PC, in %LOCALAPPDATA%\WordOnAirLabs\WordOnAirSlides\settings.json. The logo file itself stays where you saved it. Those details are written into the PowerPoint file you create, because that is the slide you asked for.

The World English Bible and the Urdu Geo Version are included in the app. Looking up a verse does not send the reference to WordOnAir Labs.

2. Information the Chrome extension handles

The extension does not ask for your name, email, phone number, contacts, or a Google account. It does not read the pages you visit, and it does not run on websites.

The church name, theme, and language are stored in Chrome on this computer. A logo you choose is stored in that same place when it fits, and is written only into the PowerPoint file you download. Looking up a verse does not send the reference, the church name, or the logo to WordOnAir Labs. The Bible text is inside the extension.

3. Why that information is stored

  • To remember the church name, logo, theme, and language the next time you open WordOnAir Slides.
  • To put that church name and logo on the PowerPoint slides you create.

WordOnAir Labs does not sell personal information and does not use advertising IDs.

4. Permissions

The Windows app does not request internet access, camera, microphone, location, or contacts. It reads a logo image only when you choose one, and it writes the PowerPoint file you ask it to save.

The Chrome extension requests storage so it can remember those church settings in the browser. It does not request access to websites, camera, microphone, location, or contacts.

5. Scripture

World English Bible text is public domain. Urdu Geo Version text is included under CC BY-NC-ND 4.0. The wording is copied and is not rewritten. Slides that include Urdu credit “Urdu Geo Version · World English Bible”.

6. Children

WordOnAir Slides is a general-audience religious text tool. It has no ads and does not knowingly collect personal information from children.
