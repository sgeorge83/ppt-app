WordOnAir Slides helps pastors place Scripture on the PowerPoint slides they already use in church.

Type a reference such as John 3:16, search a word, or choose a sermon topic. Each slide can show the World English Bible, the Urdu Geo Version, or both. Urdu is set right to left. The wording is copied from those Bibles and is not rewritten.

Both texts are free resources. The World English Bible is in the public domain. The Urdu Geo Version is shared under CC BY-NC-ND 4.0. A bilingual slide credits “Urdu Geo Version · World English Bible”.

Add the church name, a logo, and one of four themes: Morning Air, Parchment, Linen, or Chapel. Then download a PowerPoint file. To use a presentation you already have, copy these slides into that file in PowerPoint.

WordOnAir Slides is free. There is no account, no advertising, and no collection of personal information. The church name and logo stay in this browser. The Bible text is included in the extension, so a lookup does not use the internet.
